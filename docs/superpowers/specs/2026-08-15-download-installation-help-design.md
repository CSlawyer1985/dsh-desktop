# 下载区首次运行说明设计

## 目标

在不改变现有主页视觉语言的前提下，让下载用户理解系统拦截的原因，并能独立完成 DeepSeek Harness 的首次运行。首页只展示面向用户的安装帮助，不再链接内部代码签名配置指南。

## 页面位置与交互

- 说明放在各平台下载卡片之后、下载区普通备注之前。
- macOS、Windows、Linux 标签页分别包含本平台的说明，切换标签页时只显示当前平台内容。
- 使用原生 `<details>` 和 `<summary>` 实现折叠，标题为“下载后打不开？查看安装方法”。默认收起，点击后展开。
- 原生折叠结构保留键盘操作和屏幕阅读器语义，不增加弹窗或新的页面跳转。

## 对客文案

### 通用说明

当前安装包暂未取得平台代码签名。系统提示并不表示从本站下载的文件真的损坏。用户应只从本站或项目 GitHub Releases 下载，并仅对 DeepSeek Harness 单独放行。

### macOS

1. 打开 DMG，将 DeepSeek Harness 拖入“应用程序”。
2. 尝试打开一次；如果被拦截，进入“系统设置 → 隐私与安全性”，点击“仍要打开”。
3. 如果仍显示“已损坏”，打开“终端”，执行只移除本应用下载隔离标记的命令：

   ```bash
   xattr -dr com.apple.quarantine "/Applications/DeepSeek Harness.app"
   ```

4. 再次从“应用程序”打开。明确提示不要全局关闭 Gatekeeper。

### Windows

1. 双击安装器或便携版。
2. 出现“Windows 已保护你的电脑”时点击“更多信息”。
3. 核对应用名称和下载来源后，点击“仍要运行”。

### Linux

1. 为 AppImage 增加执行权限：`chmod +x DeepSeek-Harness-*.AppImage`。
2. 双击运行，或在终端执行 `./DeepSeek-Harness-*.AppImage`。

## 视觉规范

- 延续现有深蓝黑背景、冷灰文字、蓝色强调和细描边。
- 说明组件使用现有卡片圆角与边框变量，不引入新的渐变、弹窗或高饱和警告色。
- 摘要行包含内联 SVG 的信息图标和展开箭头；箭头在展开时旋转。
- 步骤采用紧凑编号列表；命令使用现有等宽字体与代码块语言，并提供“复制命令”按钮。
- 正文字号桌面端和移动端均不小于 16px，行高保持 1.7；长命令允许横向滚动，按钮保持可触控尺寸。

## 代码范围

- `site/index.html`：加入三个平台的折叠说明，删除“代码签名指南”对客链接，保留必要的版本和 CLI 前置条件说明。
- `site/style.css`：增加安装说明、步骤列表、命令行和移动端样式。
- `site/main.js`：复用并抽象现有复制逻辑，为 macOS 命令提供复制功能。

不修改构建、签名、Release、Cloudflare 或应用本体代码。

## 验收标准

- macOS、Windows、Linux 标签下均能找到对应说明，内容不会串台。
- macOS 命令可复制，复制内容与页面展示完全一致。
- 键盘可以聚焦并展开说明；焦点样式清晰。
- 360px 移动端无横向溢出，下载按钮、折叠标题和命令区不互相挤压。
- 页面默认状态仍以下载按钮为视觉重点，展开说明后步骤清楚可读。
- 页面不再出现“代码签名指南”链接或内部证书配置内容。
