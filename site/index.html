DeepSeek Harness 桌面客户端

一点即开

DeepSeek Harness 的跨平台桌面封装：双击图标，自动拉起 dsh web 服务， 独立窗口加载 UI，退出自动清理。无需再打开终端、输入网址。

三个核心设计

把"启动服务"这件事，
从终端里拿掉

桌面端只做一件事：让 DeepSeek Harness 像普通 App 一样，双击即用。

自动拉起服务

启动时探测本地端口：已有 dsh web 在跑就直接复用；没有则用内置 Node 运行时自动拉起，就绪后加载 UI，无需任何命令。

独立桌面窗口

无地址栏、无标签页的原生窗口，固定到 Dock 或任务栏后与普通 App 无异；服务意外退出会弹窗提示，一键重启。

完整复用配置

直接使用本机 ~/.dsh 下的 profile、插件与会话数据，与命令行体验完全一致；退出时自动关闭自己拉起的服务，不误伤其他实例。

每一次启动都有迹可循

工作原理

状态全程可见：日志写入应用数据目录，服务守护进程意外退出时弹窗提示，任何环节出问题都能快速定位。

探测端口

检查 127.0.0.1:3080 是否已有 DSH 服务（按 __DSH_BOOT__ 标记识别）。

发现 CLI

查找本机 npm 全局安装或 npx 缓存中的 @deepseek-ai/dsh，找不到时可用 npx 在线启动。

拉起并等待就绪

用 Electron 内置 Node 运行时启动 dsh --profile web，轮询直到服务就绪（最长 120 秒）。

守护与清理

加载 UI；退出应用时自动关闭自己拉起的服务进程，复用中的外部实例保持不动。
